# Bomberman Roguelike — v1.1

Versión GitHub-ready con una progresión roguelike más profunda y basada en decisiones.

## Estructura
- `index.html` — interfaz y canvas.
- `styles.css` — estilo visual y componentes de recompensa.
- `game.js` — lógica completa del juego.

## Sistemas roguelike v1.1
- Runs numeradas y persistentes.
- Profundidades procedurales.
- Oro/monedas como economía de la run.
- 8 reliquias únicas con efectos pasivos y rarezas.
- Recompensas con rareza: comunes, poco comunes, raras y épicas.
- Reroll de recompensas usando monedas.
- Opción de saltar una recompensa a cambio de monedas.
- 5 tipos de sala: Normal, Élite, Tesoro, Maldita y Santuario.
- Los modificadores alteran enemigos, velocidad, densidad y botín.
- Powerups clásicos siguen existiendo.
- Mejor profundidad y mejor puntaje persistentes.
- Movimiento ajustado para ser independiente de los FPS.
- Compatible con PC y controles táctiles.

## Ejecutar
Abrir `index.html` directamente o publicarlo en GitHub Pages. No requiere Node ni backend.

## Controles
- WASD / flechas: mover
- Espacio / Z / botón 💣: bomba
- P / Escape: pausa

## GitHub Pages
Subir los archivos del proyecto al repositorio y configurar Pages para servir desde la rama/carpeta donde esté `index.html`.
